# Smart Business OS

AI-powered business dashboard with a React client and Node.js server.

## Project Structure

- `client/` - Vite + React frontend
- `server/` - Express + MongoDB backend
- `setup.sh` - project generator script

## Quick Start

From the project root:

```bash
npm install
```

Run the apps separately:

```bash
npm run dev:client
npm run dev:server
```

Or work inside each package directly:

```bash
cd client
npm install
npm run dev
```

```bash
cd server
npm install
npm run dev
```
